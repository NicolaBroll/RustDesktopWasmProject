BinariGit @VERSION@ for Windows (x86_64)

Requirements: Git for Windows (https://git-scm.com/download/win) installed, with git.exe on
PATH ("Git from the command line and also from 3rd-party software" in its installer).
BinariGit runs git for every operation and does not bundle it.

Start: double-click BinariGit.exe (no installer; the folder can live anywhere).
Opening a repository directly: BinariGit.exe C:\path\to\repo

The build is not signed: Windows SmartScreen may warn the first time ("More info" > "Run anyway").
